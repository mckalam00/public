## 이 플레이북의 목적

건설 조달의 대부분은 아직 **전화·팩스·엑셀·메모**로 처리됩니다. 그 결과 같은 자재도 현장마다 단가가 크게 다르고, 공급사를 검증할 방법이 없으며, 발주 데이터가 흩어져 원가 분석과 예산 수립이 어렵습니다.

이 플레이북은 건설현장이 **"수기 조달 → 디지털 조달 → AI 기반 스마트 조달"** 로 넘어가는 과정을 **바로 실행할 수 있는 플레이(Play) 단위**로 정리합니다. 각 플레이에는 목표, As-Is/To-Be, 실행 단계, AI 에이전트의 역할, KPI, 체크리스트가 들어 있습니다.

## 핵심 메시지 (One-Page Summary)

| # | 원칙 | 한 줄 설명 |
|---|------|-----------|
| 1 | **작게 시작해 증명하고 넓힌다** | 현장 1개·공종 1개 무료 파일럿 → 3개월 안에 절감 효과 증명 → 사업부·전사 확산 |
| 2 | **공급사가 먼저다** | 입찰을 올렸는데 응찰자가 없으면 플랫폼 가치가 0. 공급사 온보딩이 건설사 확장보다 먼저 |
| 3 | **단가는 데이터로 검증한다** | 실거래 기반 시세(GPI)와 과거 이력으로 모든 견적을 자동 검증 |
| 4 | **AI는 추천하고, 사람은 승인한다** | 공급사 추천·단가 검증·이상거래 탐지·발주 초안은 AI가, 최종 승인 권한은 사람이 가진다 |
| 5 | **모든 거래는 감사 가능해야 한다** | 요청→견적→승인→발주→검수→정산 전 과정을 로그로 남겨 투명성·ESG 대응 |
| 6 | **현장의 절감이 본사의 언어가 된다** | 현장 절감액을 원클릭 리포트로 만들어 본사 보고에 쓰게 해 내부 챔피언을 만든다 |

## 기대 효과 [POC 기반 추정]

| 지표 | 기대치 | 산정 기준 |
|------|--------|-----------|
| 연간 원가 절감 | 3.5~8.5억 원 | 연간 자재비 500억 원 건설사 기준(절감률 약 0.7~1.7%) |
| 발주 처리 시간 | 80% 단축 | 발주서 작성·승인·전달 시간, 수기 대비 |
| 공급사 온보딩 | 48시간 이내 | 기존 거래 공급사 일괄 초대 기준 |
| 물량 산출 | 수작업 대비 대폭 단축 | AI 물량산출 Beta, 도면 기반 (현장별 검증 필요) |
| 초기 도입 비용 | 0원 | 잉여자재 역경매·긴급 견적 비교 무료 |

## 사용법

- **본사 구매/SCM 팀장:** 1장 자가진단 → 8장 로드맵 → 10장 ROI 순서로 읽고 파일럿 범위를 정합니다.
- **현장소장·자재담당:** 5장 플레이 1·2·5·8(물량·견적·발주·잉여자재)부터 시작합니다.
- **재무·감사:** 7장 이상거래 룰북과 12장 거버넌스를 먼저 검토합니다.
- **공급사:** 5장 플레이 2(견적)·6(납품)·7(정산·금융)과 부록 공급사 체크리스트를 봅니다.
- **공새로 AI 개발팀:** 6~7장을 에이전트 요구사항 정의서로 사용합니다.
