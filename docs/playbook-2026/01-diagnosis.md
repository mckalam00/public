## 1장. 2026 건설 조달 환경 — 왜 지금 스마트 조달인가

### 1.1 시장 규모와 디지털 침투율

| 항목 | 수치 | 비고 |
|------|------|------|
| 국내 건설 자재·장비 조달 시장 | 약 80~120조 원 | 공새로 내부 추정 · [확인 필요] |
| 디지털 조달 침투율 | 5% 미만 | 공새로 내부 추정 · [확인 필요] |
| 오프라인(전화·팩스·엑셀) 비중 | 약 95% | 위 침투율의 역산 |

침투율이 낮다는 것은 **도입 효과가 큰 구간**이라는 뜻입니다. 경쟁 현장보다 먼저 데이터를 쌓는 쪽이 단가 협상력과 예산 정확도에서 앞서게 됩니다.

### 1.2 2026년에 조달을 바꿔야 하는 5가지 이유

| # | 동인 | 현장에 미치는 영향 | 스마트 조달의 대응 |
|---|------|------------------|------------------|
| 1 | **원가 압박** (자재비 변동·금리·PF 경색) | 마진 축소, 원가 1%가 이익을 좌우 | 실시간 단가 검증·경쟁 입찰로 구매 단가 인하 |
| 2 | **ESG·투명성 요구 강화** | 공급망 실사, 거래 투명성 증빙 요구 | 전 과정 감사 로그, 투명성 리포트 자동 생성 |
| 3 | **현장 인력 고령화·인력난** | 숙련 자재담당자 부족, 노하우 단절 | AI 물량산출·발주 초안 자동화로 업무 표준화 |
| 4 | **본사-현장 데이터 단절** | 현장별 발주 이력이 엑셀에 갇힘 | 단일 플랫폼에 데이터 통합 → 전사 원가 분석 |
| 5 | **불황기 원가 절감 수요** | 신규 IT 투자는 줄지만 절감 도구 수요는 증가 | "투자"가 아닌 "절감 도구"로 무료 시작 |

### 1.3 경쟁 환경

| 대안 | 장점 | 한계 |
|------|------|------|
| 기존 수기·전화 관행 | 익숙함, 관계 유지 | 단가 불투명, 오류, 데이터 없음 |
| 글로벌 조달 SaaS(SAP Ariba 등) | 대기업 표준, ERP 일체형 | 건설 현장 특화 부족, 높은 도입 비용·기간 |
| 그룹사 SI 조달 모듈 | 계열사 내 통합 | 외부 공급사 네트워크 한정 |
| 건설사 자체 개발 | 맞춤형 | 개발·유지 비용, 공급사 네트워크 부재 |
| **건설 특화 3-사이드 플랫폼(공새로)** | 건설사·공급사·관리자 연결, 자재·장비·잉여자산 전 영역 | 공급사 밀도 확보가 성패 좌우 |

## 2장. 현장 조달 Pain Point 진단

### 2.1 4대 Pain Point

| Pain Point | 현상 | 결과 | 비용 신호 |
|-----------|------|------|----------|
| **① 수기·전화 발주 오류** | 전화·메모·엑셀로 발주 | 오주문, 규격 착오, 납기 지연 | 재발주·공기 지연·긴급 구매 할증 |
| **② 불투명한 단가** | 단가 비공개, 관계 기반 거래 | 같은 자재도 현장마다 20~40% 차이 [POC 기반 추정] | 구매 단가 과다 지불 |
| **③ 공급사 검증 불가** | 납기·품질·가격 신뢰도 정보 없음 | 소수 업체 의존, 품질 클레임 | 하자 보수, 공급 중단 리스크 |
| **④ 조달 데이터 분산** | 현장별 엑셀·종이 | 원가 분석·예산 수립 불가 | 예산 초과, 협상력 상실 |

### 2.2 숨은 Pain Point

- **긴급 자재 수급:** 당일·익일 필요 자재를 전화로 수배하면서 할증 단가 수용
- **잉여자재 처리:** 준공·공정 전환 시 남은 자재를 폐기하거나 헐값 처분
- **쪼개기·수의계약 관행:** 승인 한도를 피하려 발주를 나누는 관행 → 감사 리스크
- **검수-정산 불일치:** 납품 수량·규격과 세금계산서 불일치, 수작업 대사
- **공급사 현금흐름:** 납품 후 대금 수령까지 60~120일 대기 → 공급사가 단가에 금융비용 전가

### 2.3 이해관계자별 진짜 관심사

| 이해관계자 | 진짜 관심사 | 설득 언어 |
|-----------|------------|----------|
| 현장소장 | 공기 준수, 자재 제때 도착, 업무 편의 | "전화 돌릴 시간이 줄어듭니다" |
| 자재담당 | 견적 비교 시간, 발주 실수 | "견적 3~5개를 한 화면에서" |
| 본사 구매팀 | 단가 경쟁력, 공급사 풀, 표준화 | "전사 단가를 한눈에, 공급사 성과 점수까지" |
| CFO·재무 | 원가 절감액, 현금흐름, 감사 대응 | "조달비 X% 절감 = 연간 XX억 원" |
| 감사·준법 | 부정 방지, 증빙 | "모든 거래가 로그로 남고 이상거래는 자동 탐지" |
| 공급사 | 수주 기회, 빠른 대금 회수 | "새 현장 입찰 기회 + 조기 결제" |

## 3장. 조달 성숙도 자가진단

### 3.1 성숙도 5단계 모델

| 레벨 | 명칭 | 특징 | 다음 단계로 가는 핵심 행동 |
|------|------|------|------------------------|
| **L0** | 수기 조달 | 전화·팩스·메모, 개인 노하우 의존 | 발주 요청을 한 곳으로 모은다 |
| **L1** | 기록 조달 | 엑셀·메신저로 기록, 현장별 상이 | 품목·양식을 표준화한다 |
| **L2** | 디지털 조달 | 전자 발주·전자 견적, 승인 흐름 존재 | 복수 견적·역경매를 기본값으로 |
| **L3** | 데이터 조달 | 단가 이력·공급사 성과 데이터 축적, 대시보드 | AI 단가 검증·이상 탐지 적용 |
| **L4** | 스마트 조달 | AI 추천·자동 발주·예측, ERP·금융 연동 | 수요 예측·전사 최적화 |

### 3.2 자가진단 체크리스트 (20문항)

각 문항에 **예=1점, 아니오=0점**. 합계로 레벨을 판정합니다.

**A. 요청·계획 (Plan)**
- [ ] A1. 자재 소요를 공정표와 연결해 미리 계획한다
- [ ] A2. 발주 요청이 하나의 시스템(또는 양식)으로 모인다
- [ ] A3. 품목명·규격을 표준 코드로 관리한다
- [ ] A4. 물량 산출 결과와 실제 발주량을 비교한다

**B. 소싱·견적 (Source)**
- [ ] B1. 주요 품목은 3개 이상 공급사 견적을 비교한다
- [ ] B2. 신규 공급사를 찾는 공식 경로가 있다
- [ ] B3. 공급사의 납기·품질 이력을 점수로 관리한다
- [ ] B4. 견적 단가를 과거 거래·시세와 비교 검증한다

**C. 발주·계약 (Order)**
- [ ] C1. 발주서가 전자 문서로 생성·전달된다
- [ ] C2. 금액별 승인 권한(전결 규정)이 시스템에 반영돼 있다
- [ ] C3. 반복 발주 품목은 단가 계약으로 관리한다
- [ ] C4. 긴급 발주 비율을 측정한다

**D. 납품·검수·정산 (Deliver & Pay)**
- [ ] D1. 납품 수량·규격을 모바일로 검수·기록한다
- [ ] D2. 발주-검수-세금계산서 3-way 대사를 자동으로 한다
- [ ] D3. 공급사 대금 지급 기일을 관리·준수한다
- [ ] D4. 잉여자재를 재사용·재판매하는 프로세스가 있다

**E. 데이터·거버넌스 (Govern)**
- [ ] E1. 현장별·품목별 단가를 본사에서 실시간으로 본다
- [ ] E2. 발주 쪼개기·특정 업체 집중 등 이상 패턴을 점검한다
- [ ] E3. 조달 데이터가 ERP와 연동된다
- [ ] E4. 조달 KPI(절감액·리드타임·경쟁률)를 정기 리뷰한다

### 3.3 점수 해석

| 합계 | 레벨 | 권장 시작 플레이 |
|------|------|----------------|
| 0~4 | L0 수기 조달 | 플레이 5(발주 디지털화) + 플레이 8(잉여자재 무료 역경매)로 첫 경험 |
| 5~9 | L1 기록 조달 | 플레이 1(소요 계획 표준화) + 플레이 2(복수 견적) |
| 10~14 | L2 디지털 조달 | 플레이 3(단가 검증) + 플레이 4(입찰·역경매) |
| 15~18 | L3 데이터 조달 | 7장 이상거래 룰북 + 플레이 7(정산·금융) |
| 19~20 | L4 스마트 조달 | 6장 AI 에이전트 전면 적용, 수요 예측 |

> 💡 **진단 운영 팁:** 같은 설문을 현장소장·자재담당·본사 구매팀이 각자 응답하게 하면, 응답 차이 자체가 "본사-현장 인식 격차"를 보여주는 좋은 진단 자료가 됩니다.
