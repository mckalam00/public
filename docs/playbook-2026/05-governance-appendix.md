## 11장. 시스템 연동 & 데이터 표준

### 11.1 연동 대상

| 시스템 | 연동 내용 | 방향 | 우선순위 |
|--------|----------|------|---------|
| ERP (SAP·더존·영림원 등) | 발주 → 구매전표, 공급사·품목 마스터, 지급 결과 | 양방향 | 확산 단계(3단계) |
| 전자세금계산서 | 세금계산서 수신 → 3-way 대사 | 수신 | 2~3단계 |
| 그룹웨어·전자결재 | 승인 요청·결과 | 양방향 | 고객 요청 시 |
| 공공 조달(나라장터 등) | 공공 공사 조달 정보 | 수신 | 장기 |
| 금융(KODIT 연계 등) | 조기 결제 신청·승인 | 양방향 | 4단계(파일럿 예정) |

### 11.2 데이터 표준

| 데이터 | 표준화 항목 | 이유 |
|--------|-----------|------|
| **품목 마스터** | 품목코드, 대·중·소분류, 규격, 단위 | 단가 비교·검증의 기반. 건설 자재는 규격이 매우 비표준적이므로 가장 먼저 투자해야 할 영역 |
| 공급사 마스터 | 사업자번호, 업종·면허, 취급 품목, 납품 지역, 계좌(검증) | 추천·이상거래 탐지의 기반 |
| 현장 마스터 | 현장코드, 위치, 공정 단계, 담당자 | 지역·현장별 비교 |
| 거래 이벤트 | 요청·견적·승인·발주·검수·정산의 시각·주체·값 | 감사 로그, KPI 산출 |
| 단위 환산 | ㎥·톤·개·본 등 환산 규칙 | 단가 비교 오류 방지 |

### 11.3 보안·권한

- **최소 권한 원칙:** 현장 사용자는 자기 현장, 본사는 전사, 공급사는 자기 거래만 조회
- **민감 정보 분리:** 계좌·개인 정보는 암호화 저장, 열람 로그 기록
- **단가 정보 보호:** 공급사 간 타사 견적 단가 비공개(역경매는 순위·최저가만 공개 등 방식별 정책)
- **감사 로그 불변성:** 거래·승인 로그는 수정 불가, 정정은 새 이력으로 추가
- **AI 학습 데이터:** 고객사 데이터의 학습 활용 범위를 계약에 명시

## 12장. 거버넌스 & 컴플라이언스

### 12.1 조달 거버넌스 체계

| 구성 | 내용 |
|------|------|
| 조달 정책 | 입찰 의무 금액, 견적 최소 수, 수의계약 허용 사유 |
| 전결 규정 | 금액·품목·현장별 승인권자, 시스템 설정과 일치 여부 정기 점검 |
| 직무 분리 | 요청-승인-검수-정산 분리 |
| 공급사 관리 | 등록 심사, 정기 평가(Trust Score), 제재·해제 절차 |
| AI 거버넌스 | 에이전트별 책임자, 임계값 변경 승인 절차, 모델 변경 이력, 정기 성능 리뷰 |

### 12.2 검토가 필요한 법규 영역 (법무 검토 필수)

> 아래는 검토 영역 안내이며 법률 자문이 아닙니다. 적용 여부와 세부 요건은 반드시 법무 검토를 거칩니다.

| 영역 | 관련 법령(예) | 플레이북 내 영향 |
|------|-------------|----------------|
| 하도급 거래 | 하도급거래 공정화에 관한 법률 | 대금 지급 기일, 부당 단가 결정 금지 → 역경매·단가 협상 설계 시 유의 |
| 건설업 | 건설산업기본법 | 하도급·자재 조달 관련 의무 |
| 전자 거래 | 전자문서 및 전자거래 기본법 | 전자 발주서·전자 계약의 효력 |
| 개인정보 | 개인정보 보호법 | 공급사 대표자·임직원 정보 대조(7장 R5·R12) |
| 공정거래 | 독점규제 및 공정거래에 관한 법률 | 입찰 담합 탐지, 정보 공유 범위 |
| 세무 | 부가가치세법 등 | 전자세금계산서·3-way 대사 |

### 12.3 ESG 연계

- 조달 투명성 리포트(경쟁 입찰 비율, 공급사 다양성, 이상거래 처리 현황) 자동 생성
- 잉여자재 재사용량 → 자원 순환 실적으로 활용
- 공급사 조기 결제 → 중소 협력사 상생 지표로 활용

## 13장. 리스크 & 대응

| 리스크 | 수준 | 증상 | 대응 |
|--------|------|------|------|
| **공급사 밀도 부족** | 높음 | 입찰 응찰자 0~1개 | 공급사 온보딩을 건설사 확장보다 먼저, 공급사:건설사 비율 주간 모니터링, 기존 거래처 일괄 초대 |
| **현장 사용 저항** | 높음 | 플랫폼 밖 전화 발주 지속 | 무료 진입점(잉여자재·긴급 견적), 모바일 우선 UX, 현장 챔피언 지정 |
| **파일럿 → 계약 전환 지연** | 높음 | 예산 동결, 의사결정 지연 | 사전 합의한 성공 기준, CFO 언어의 ROI 리포트, 현장·구매·재무 다중 접점 |
| **품목 비표준으로 검증 오류** | 중간 | 단가 경고 오탐 다발 | 품목 마스터 우선 정비, 판단불가 처리, 오탐 피드백 루프 |
| **공급사 가격 투명화 거부** | 중간 | 공급사 이탈, 견적 회피 | 조기 결제·우선 노출 등 참여 인센티브, 단가 비공개 정책 명확화 |
| **AI 권고 과신/불신** | 중간 | 무조건 수용 또는 무시 | 근거 표시, 수용률·정확도 공개, 사람 승인 필수 |
| **데이터 보안 사고** | 높음 | 단가·계좌 정보 유출 | 최소 권한, 암호화, 접근 로그, 정기 점검 |
| **건설 경기 하강** | 중간 | 신규 현장·거래액 감소 | "원가 절감 도구" 포지셔닝, 무료 시작으로 도입 장벽 최소화 |

### 검증이 필요한 가정

1. 건설사가 거래 수수료·구독료를 절감액 대비 합리적으로 수용할 것
2. 건설 자재 품목 표준화가 실무적으로 충분한 수준까지 가능할 것
3. 금융 기관이 플랫폼 거래 데이터를 신용 판단에 활용할 것
4. 현장 사용자가 모바일 검수·발주를 일상 업무로 받아들일 것

→ 파일럿 90일 안에 고객 인터뷰·사용 데이터로 각 가정을 검증하고, 틀린 가정은 즉시 설계를 수정합니다.

## 부록 A. 템플릿

### A-1. 견적 요청서 필수 항목

| 필드 | 필수 | 설명 |
|------|:---:|------|
| 현장코드 / 납품지 | ✅ | 주소·하차 조건 |
| 품목코드 / 품목명 / 규격 | ✅ | 품목 마스터 기준 |
| 수량 / 단위 | ✅ | 단위 환산 규칙 준수 |
| 희망 납기 | ✅ | 분할 납품 여부 |
| 운반·하차 조건 | ✅ | 단가 포함 여부 명시 |
| 결제 조건 | ✅ | 지급 기일·방식 |
| 회신 마감 | ✅ | 일시 |
| 품질 요구사항·첨부 | 선택 | 시험성적서·인증 등 |

### A-2. 공급사 평가표 (Supplier Trust Score 구성 예)

| 항목 | 측정 방법 | 데이터 출처 |
|------|----------|-----------|
| 납기 준수 | 기한 내 납품 비율 | 검수 기록 |
| 품질 | 클레임·반품 비율 | 검수·클레임 기록 |
| 가격 안정성 | 단가 변동 폭, 시세 대비 수준 | 견적·발주 기록 |
| 응답성 | 견적 회신율·시간 | 견적 기록 |
| 거래 이력 | 거래 기간·건수 | 발주 기록 |
| 서류 적정성 | 필수 서류 유효성 | 등록 정보 |

> 가중치는 고객사·품목군별 설정값으로 관리합니다.

### A-3. 파일럿 성공 기준 합의서 항목

- 파일럿 범위(현장·공종·기간)
- 기준가 정의(10.1 주의사항)
- 성공 KPI와 목표치(예: 전자 발주 비율, 평균 견적 수, 절감률)
- 데이터 제공 범위·보안 조건
- 성공 시 다음 단계와 조건

## 부록 C. 용어집

| 용어 | 설명 |
|------|------|
| GPI (Gongsaero Price Index) | 플랫폼 실거래 기반 자재 시세 인덱스 |
| Supplier Trust Score | 납기·품질·가격 안정성·거래 이력 기반 공급사 신뢰 점수 |
| 역경매 | 구매자가 조건을 제시하고 공급사들이 가격을 낮춰가며 경쟁하는 방식 |
| 3-way 대사 | 발주서·검수 기록·세금계산서의 수량·금액 일치 확인 |
| 총 도착가(Landed Cost) | 단가 + 운반·하차·부대비용을 포함한 실제 도착 비용 |
| 전결 규정 | 금액·사안별 승인권자 규정 |
| 직무 분리 | 한 사람이 요청·승인·검수·정산을 모두 하지 못하게 나누는 통제 |
| Human-in-the-Loop | AI 결과를 사람이 확인·승인하는 운영 방식 |
| QBR | 분기별 사업 리뷰(Quarterly Business Review) |
| PLG | 제품 사용 경험으로 도입을 이끄는 방식(Product-Led Growth) |
| MSA | 전사 기본 계약(Master Service Agreement) |
