## 8장. 역할과 책임 (RACI)

R=실행, A=최종책임, C=협의, I=공유

| 활동 | 현장소장 | 자재담당 | 본사 구매/SCM | 재무 | 감사·준법 | 공급사 | 공새로 CSM |
|------|:-------:|:-------:|:-----------:|:---:|:-------:|:-----:|:---------:|
| 소요 계획·물량 확정 | A | R | C | I | – | – | C |
| 견적 요청·공급사 선정 | C | R | A | – | I | R(응찰) | C |
| 단가 검증 결과 검토 | I | R | A | C | I | – | C |
| 입찰·역경매 운영 | I | R | A | – | C | R(응찰) | C |
| 발주 승인 | 전결 규정 | R | 전결 규정 | 전결 규정 | – | I | – |
| 납품·검수 | A | R | I | – | – | R(납품) | – |
| 정산·지급 | I | C | C | A/R | I | C | – |
| 이상거래 검토 | I | I | C | C | A/R | – | – |
| 품목·전결 규정 설정 | C | C | A/R | C | C | – | C |
| KPI 리뷰(QBR) | C | C | A | C | I | – | R |

### 역할별 첫 주 할 일

- **현장소장:** 파일럿 공종 지정, 잉여자재 1건 등록해보기
- **자재담당:** 기존 거래 공급사 리스트 업로드, 다음 발주 1건을 플랫폼에서 견적 비교
- **본사 구매/SCM:** 파일럿 범위·성공 기준 확정, 전결 규정·주요 품목 코드 제공
- **재무:** 정산·지급 프로세스 담당자 지정, 3-way 대사 기준 확인
- **감사·준법:** 이상거래 룰 초기 임계값 검토, 알림 열람 권한자 지정
- **공급사:** 등록 서류 제출, 카탈로그·단가표 등록

## 9장. 도입 로드맵

### 9.1 단계별 로드맵

| 단계 | 기간 | 범위 | 핵심 활동 | 완료(Exit) 기준 |
|------|------|------|----------|----------------|
| **0. 무료 파일럿** | Week 1~2 | 현장 1개 | 잉여자재 역경매·긴급 견적 비교 무료 사용 | 첫 거래 1건 이상, 현장 사용자 만족 확인 |
| **1. 현장 온보딩** | Month 1 | 현장 1개 · 공종 1~2개 | 기존 공급사 일괄 초대(48시간), 발주 디지털화(플레이 5) | 파일럿 공종 발주의 대부분이 플랫폼 경유 |
| **2. 절감 증명** | Month 2~3 | 현장 1~3개 | 복수 견적·단가 검증·역경매, 절감 리포트 | 정량 절감 리포트 본사 보고 |
| **3. 확산 계약** | Month 3~6 | 3~5개 현장 → 사업부 | Pro 구독 전환, ERP 연동, 이상거래 룰 가동 | 사업부 표준 프로세스로 채택 |
| **4. 전사 파트너십** | Year 1+ | 전사 | 전사 계약(MSA), 조달 금융·GPI 데이터 구독, 수요 예측 | 전사 KPI 정기 리뷰 체계 |

### 9.2 첫 90일 상세 계획

| 주차 | 활동 | 담당 | 산출물 |
|------|------|------|-------|
| W1 | 킥오프, 파일럿 범위·성공 기준 합의, 자가진단(3장) | 본사 구매·CSM | 파일럿 계획서, 진단 결과 |
| W1~2 | 잉여자재·긴급 견적 무료 사용 | 현장 | 첫 거래 기록 |
| W2~3 | 공급사 리스트 업로드·일괄 초대 | 자재담당·CSM | 공급사 온보딩 현황 |
| W3~4 | 품목 코드 매핑, 전결 규정 설정 | 본사 구매 | 품목 마스터 v1, 승인 경로 |
| W5~6 | 파일럿 공종 전자 발주 전환 | 자재담당 | 전자 발주 비율 |
| W6~8 | 복수 견적 + 단가 검증 기본 적용 | 자재담당·구매 | 견적 비교·검증 기록 |
| W8~10 | 역경매/입찰 1~2회 실행 | 구매 | 입찰 결과·경쟁률 |
| W10~11 | 이상거래 룰 시범 가동(알림만) | 감사 | 룰별 알림·오탐 현황 |
| W12 | 절감 효과 리포트, 확산 의사결정 회의 | 본사·CSM | **절감 리포트(본사 보고용)**, 확산 계획 |

### 9.3 확산 원칙 — "현장 → 사업부 → 전사"

1. 최초 계약 시 확산 단계(현장 3개 → 사업부 → 전사)와 **단계별 KPI를 사전 합의**
2. 각 단계 전환은 KPI 달성 여부로 판단(감이 아닌 데이터)
3. 공급사 밀도 먼저: 신규 현장 투입 전 해당 지역·공종 공급사 풀 확인
4. 분기별 사업 리뷰(QBR)에서 절감 성과를 고객사 내부 보고 자료로 패키징

## 10장. KPI 정의서 & ROI 산정

### 10.1 KPI 정의

| 영역 | KPI | 산식 | 측정 주기 |
|------|-----|------|----------|
| 비용 | **단가 절감액** | Σ (기준가 − 실구매 단가) × 수량 | 월 |
| 비용 | 단가 절감률 | 단가 절감액 / Σ (기준가 × 수량) | 월 |
| 비용 | 긴급 발주 비율 | 긴급 발주 건수 / 전체 발주 건수 | 월 |
| 속도 | 발주 처리 리드타임 | 발주 요청 → 공급사 수주 확인 평균 시간 | 주 |
| 속도 | 견적 회신 시간 | 견적 요청 → 회신 평균 시간 | 주 |
| 경쟁 | 평균 견적·응찰 수 | 견적(응찰) 수 / 요청(입찰) 건수 | 월 |
| 경쟁 | 입찰 참여 공급사 비율 | 응찰 공급사 수 / 초대 공급사 수 | 월 |
| 품질 | 납기 준수율 | 기한 내 납품 건수 / 전체 납품 건수 | 월 |
| 품질 | 검수 불일치율 | 불일치 검수 건수 / 전체 검수 건수 | 월 |
| 커버리지 | 전자 발주 비율 | 플랫폼 경유 발주 금액 / 전체 발주 금액 | 월 |
| 커버리지 | 단가 검증 커버리지 | 검증된 발주 금액 / 전체 발주 금액 | 월 |
| 통제 | 이상거래 알림 처리율 | 기한 내 검토 완료 알림 / 전체 알림 | 월 |
| 통제 | 룰 오탐률 | 정상 종결 알림 / 전체 알림 | 분기 |
| AI | AI 권고 수용률 | 수용된 추천·초안 / 전체 추천·초안 | 월 |

> **기준가 정의 주의:** 절감액은 "무엇 대비 절감인가"에 따라 크게 달라집니다. 파일럿 시작 전 기준가 정의(① 직전 거래 단가 ② 최초 견적가 ③ 시세)를 고객사와 **서면 합의**해야 절감 리포트의 신뢰성이 확보됩니다.

### 10.2 ROI 산정 방법

```
연간 절감 효과 = 단가 절감 + 업무시간 절감 + 긴급구매 할증 절감 + 잉여자재 회수 + 오류·재발주 절감

ROI = (연간 절감 효과 − 연간 플랫폼 비용) / 연간 플랫폼 비용
투자 회수 기간(개월) = 연간 플랫폼 비용 / (연간 절감 효과 / 12)
```

| 항목 | 산식 | 필요 데이터 |
|------|------|-----------|
| 단가 절감 | 연간 자재비 × 단가 절감률 | 자재비, 파일럿 절감률 |
| 업무시간 절감 | 연간 발주 건수 × 건당 절감 시간 × 인건비 시급 | 발주 건수, 전후 처리시간 |
| 긴급구매 할증 절감 | 긴급 발주 금액 감소분 × 평균 할증률 | 긴급 발주 금액, 할증률 |
| 잉여자재 회수 | 처분 회수액 − (기존 처분 회수액 − 폐기 비용) | 잉여자재 거래 기록 |
| 오류·재발주 절감 | 감소한 재발주 건수 × 건당 비용 | 정정·취소 건수 |

**산정 예시 (가정값 — 실제 고객 데이터로 대체 필요)**

| 가정 | 값 |
|------|----|
| 연간 자재비 | 500억 원 |
| 단가 절감률 범위 | 0.7%~1.7% [POC 기반 추정] |
| → 단가 절감액 | **3.5억~8.5억 원/년** |

업무시간·긴급구매·잉여자재 절감은 고객사 데이터가 있어야 산정 가능하므로 파일럿 기간에 측정합니다.
