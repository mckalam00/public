## 1. 메시지 설계 (한 문장 → 세 개의 증거)

**핵심 메시지 (영상이 끝나고 남아야 할 한 문장)**

**스토리 구조: Before → Turn → After → Proof → CTA**

## 3. 스토리보드 + 내레이션 스크립트 (45초 마스터)

한국어 내레이션은 초당 약 4.5~5음절로 계산했다. 음절 수가 이보다 많으면 문장을 줄인다.

| 씬 | 시간 | 화면 (비주얼) | 화면 텍스트 | 내레이션 (VO) | 모션 기법 |
|---|---|---|---|---|---|
| **S1 Hook** | 0:00–0:05 | 건설 현장 실루엣 위로 전화 아이콘 진동, 카톡 말풍선, 엑셀 시트가 어지럽게 쌓임 | 전화 · 카톡 · 엑셀 | "전화, 카톡, 엑셀로 관리하던 건설 현장 구매." | 아이콘 팝인 + 카메라 흔들림(wiggle), 화면이 점점 꽉 참 |
| **S2 Problem** | 0:05–0:10 | 세 사람의 말풍선(현장·본사·경영진, p.7)이 차례로 뜨고, 아래 데이터 조각이 흐려지며 사라짐 | 데이터가 남지 않습니다 | "업무는 반복되고, 기준은 없고, 리스크는 보이지 않습니다." | 말풍선 스태거 등장(4f 간격), 데이터 파티클 디졸브 |
| **S3 Turn** | 0:10–0:14 | 흩어진 아이콘이 공새로 로고 심볼로 빨려 들어가고 네이비 배경으로 전환 | **AI 시대에는 기업 데이터로 통합 관리하세요** (주황 강조) | "이제, 기업 데이터로 통합 관리하세요." | **Chaos→Order 수렴**(이 영상의 시그니처 모션), 로고 원형 라인 드로잉 |
| **S4 Solution** | 0:14–0:26 | 노트북 프레임 안에서 5단계 UI가 좌→우로 넘어감: 업체 지도 검색 → 견적 비교(최저가 강조) → 발주 관리 대시보드 → 정산 버튼 클릭 → 분석 차트 | 주문 요청 → 비교 견적 → 발주 → 정산 → 분석 / 배지: **발주처리 3~4일 → 1일** | "주문 요청부터 비교 견적, 발주, 정산, 분석까지. 현장의 모든 조달이 하나의 화면에서 끝납니다." | 디바이스 목업 + 가상 커서 클릭, 스텝 인디케이터 진행 바, 배지 스케일 바운스 |
| **S5 Platform** | 0:26–0:32 | 로고를 중심으로 4개 서비스 원이 궤도를 돎(p.10) | 현장 조달 · 공새로몰 · 잉여자산 거래 · 통합 관리 | "맞춤형 커머스와 잉여 자산 거래, 본사 통합 관리까지." | 궤도 회전 + 원형 아이콘 순차 하이라이트 |

## 4. 비주얼 시스템 (소개서에서 추출)

| 토큰 | 값 (소개서 기준 근사치, 브랜드 가이드로 최종 확인) | 용도 |
|---|---|---|
| Navy | `#0B2A6B` | 배경, 전환 씬, CTA |
| Primary Blue | `#4A7CF0` | 강조 텍스트, UI 하이라이트 |
| Accent Orange | `#F47B20` | 핵심 카피 1곳, 배지, CTA 버튼 (씬당 1회만) |
| Light Blue BG | `#EEF4FF` | UI 카드 배경 |
| Text | `#111111` / `#FFFFFF` | 본문 |
| Font | Pretendard (Bold 헤드라인 / Medium 본문) | 소개서와 동일 계열 |

- **화면 텍스트는 한 화면 12자 이내, 최소 48px(1080p 기준)**. 숫자는 120px 이상.
- 일러스트는 소개서의 **라인 아이콘 + 라운드 카드** 스타일을 유지한다. 3D 실사와 섞지 않는다.
- 주황은 "결과·전환" 순간(S3 카피, S4 배지, S8 CTA)에만 써서 시선을 모은다.

## 5. 핵심 모션 스킬 7가지

| 스킬 | 어디에 | 구현 팁 |
|---|---|---|
| 1. **Chaos → Order 수렴** | S1→S3 | 흩어진 레이어를 로고 중심점으로 모으는 Position 키프레임 + Scale 축소. 모션 블러 ON. 영상의 기억점이므로 가장 공을 들인다 |
| 2. **Kinetic Typography** | 전 씬 | 단어 단위 마스크 리빌(아래→위 20px, 8f). 강조 단어만 색 전환 |
| 3. **UI 목업 시연** | S4 | 실제 화면을 Figma에서 다시 그려 레이어로 분리 → AE로 가져옴. 가상 커서 + 클릭 리플로 "쉽다"를 보여줌 |
| 4. **숫자 카운트업** | S7 | 정수로 반올림해 표시, 마지막 6f는 감속. `+`, `%`는 고정 레이어 |
| 5. **데이터 플로우 라인** | S4·S6 | 점선 Trim Path 애니메이션으로 "연결"을 표현(소개서 p.8의 점선 화살표와 통일) |
| 6. **지도 핀 스태거** | S7 | 핀 30~50개를 2f 간격으로 드롭, 오버슈트 이징 |
| 7. **매치 컷 전환** | 씬 사이 | 원형 로고 → 원형 대시보드 차트 → 원형 서비스 궤도처럼 **원 모양**으로 이어 컷이 끊기지 않게 |

**이징 기본값**: 등장 `cubic-bezier(0.16, 1, 0.3, 1)` (easeOutExpo), 퇴장 `cubic-bezier(0.7, 0, 0.84, 0)`. 모든 씬에 같은 값을 써야 브랜드 리듬이 생긴다.

## 8. Remotion으로 만들 때 (TypeScript 예시)

씬 타이밍과 수치를 한 설정 파일에 모아 두면 숫자만 바꿔 재렌더링할 수 있다.

```bash
npx create-video@latest gongsaero-motion   # 템플릿: Blank, TypeScript
cd gongsaero-motion && npm i
```

`src/config.ts` — 하드코딩을 피하려고 수치·카피를 한곳에 둔다.

```ts
export const FPS = 30;

export type Scene = Readonly<{ id: string; seconds: number; headline: string }>;

export const SCENES: ReadonlyArray<Scene> = [
  { id: "hook", seconds: 5, headline: "전화 · 카톡 · 엑셀" },
  { id: "problem", seconds: 5, headline: "데이터가 남지 않습니다" },
  { id: "turn", seconds: 4, headline: "AI 시대에는 기업 데이터로 통합 관리하세요" },
  { id: "solution", seconds: 12, headline: "주문 요청 → 비교 견적 → 발주 → 정산 → 분석" },
  { id: "platform", seconds: 6, headline: "현장 조달 · 공새로몰 · 잉여자산 · 통합 관리" },
  { id: "asset", seconds: 5, headline: "거래가 쌓일수록 건설사는 더 똑똑해집니다" },
  { id: "proof", seconds: 5, headline: "전국 377개 현장" },
  { id: "cta", seconds: 3, headline: "조달의 기준을 새롭게, 공새로" },
];

// 담당자 확정 후 값만 교체 (기준일 함께 표기)
export const METRICS = [
  { label: "전국 도입 현장", value: 377, suffix: "+" },
  { label: "평균 비용 절감", value: 20, suffix: "%" },
  { label: "조달 업무 단축", value: 50, suffix: "%" },
] as const;

export const totalFrames = (scenes: ReadonlyArray<Scene>): number =>
  scenes.reduce((sum, s) => sum + s.seconds * FPS, 0);
```

`src/CountUp.tsx` — S7 숫자 카운트업.

```tsx
import { interpolate, useCurrentFrame, Easing } from "remotion";

type Props = Readonly<{ value: number; suffix: string; durationInFrames: number }>;

export const CountUp = ({ value, suffix, durationInFrames }: Props) => {
  const frame = useCurrentFrame();
  const current = interpolate(frame, [0, durationInFrames], [0, value], {
    extrapolateRight: "clamp",
    easing: Easing.out(Easing.cubic),
  });
  return (
    <span style={{ fontFamily: "Pretendard", fontWeight: 700, fontSize: 140 }}>
      {Math.round(current).toLocaleString("ko-KR")}
      {suffix}
    </span>
  );
};
```

`src/Root.tsx`에서 `durationInFrames={totalFrames(SCENES)}`(= 45초 × 30f = 1350f), `fps={FPS}`, `width={1920}`, `height={1080}`로 `<Composition>`을 등록하고, 각 씬은 `<Series.Sequence durationInFrames={s.seconds * FPS}>`로 이어 붙인다. 렌더링: `npx remotion render`.
